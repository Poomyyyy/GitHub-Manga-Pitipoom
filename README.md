## Ep.6 War End

ณ-บัดนี้-สงครามได้เริ่มต้นขึ้นมาแล้ว-เจ้าจิ้งจอกได้งัดพลังขึ้นมาสู้กับอสแห่งแก๊งมาเฟียสารเลว-ในการต่อสู้นั้นได้มีตั้งแต่เสียงฟ้า,-แผ่นดินไหว,-น้ำท่วมและไฟไหม้ไปทั่วโลก-ทั้งคู่ได้ต่อสู้กันไปประมาณ-7-วัน-7-คืน-จนในสุดท้าย-ทั่งคู่ได้งัดกระบวนท่ามาใช้กัน-จนสุดท้าย-เจ้าจิ้งจอกก็ได้เป็นฝ่ายชนะไป-เนื่องจากมีเพื่อนพ้องเยอะกว่าฝั่งบอสแห่งแก๊งมาเฟียสารเลว-เพื่อนพ้องของจิ้งจอกรวมพลังกำจัดฝ่ายบอสแห่งแก๊งมาเฟียสารเลวจนสำเร็จ
