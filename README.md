## Ep.5 War started

และในตอนเช้าวถัดมา-เจ้าจิ้งจอกได้รวบรวมเพื่อนฝูงที่รู้จักกันมานานได้หลายสิบคน-เพื่อไปโจมตีกับบอสแห่งแก๊งมาเฟียสารเลว-แต่ในการเดินทางนั้นเต็มไปด้วยอุปสรรรคมากมาย-เนื่องจากมีสายข่าวของ-"บอสแห่งแก๊งมาเฟียสารเลว"-มาบอกกับเจ้าตัวแล้ว-บอสจึงได้ส่งศัตรูเพื่อมาพยยามขัดขวางเจ้าจิ้งจอก-แต่เจ้าจิ้งจอก-ก็อดทนฟัดสู้-จนมาถึงบอสที่ตัวใหญ่ที่สุด-อย่างที่ทุกคนได้ทราบแล้วว่า-เจ้าจิ้งจอกได้รับมอบพลังแห่ง-อมตะ-และมีพลังอันมากมายเหลือล้น-แต่ถึงกระนั้นแล้ว-เจ้าบอสแห่งแก๊งมาเฟียสารเลว-ก็ยังคงประเมินผิดไปจากพละกำลังของเจ้าจิ้งจอก-เจ้าจิงจอก-จึงได้ทุ่มกำลังใส่กับพวกศัตรู-ที่ถูกส่งมาจากบอสแห่งแก๊งมาเฟียสารเลวไปจนหมดชั่วพริบตา-แต่ถึงกระนั้นแล้ว-เจ้าจิ้งจอกก็้ยังโกรธเครื่องเจ้าบอสแห่งแก๊งมาเฟียสารเลวเป็นอย่างมาก-พลังของเจ้าจิ้งจอกนั้น-ส่งผลสให้พื้นแผ่นดินลุกเป็นไฟขึ้นมา-จนพื้นแผ่นดินกลายเป็นท้องทะเลเพลิง-เจ้าจิ้งจอกได้เตินทางไปหาบอสแห่งแก๊งมาเฟียสารเลวโดยทันที-ท่ามกลางฝูงศัตรูที่ถูกส่งมาจากบอสแห่งแก๊งมาเฟียสารเลว-แต่เจ้าจิ้งจอกนั้นก็ยังปราบศัตรูที่ถูกส่งมาอย่างไม่หยุดไม่หย่อนแต่อย่างใด-จนถึงที่สุด-เจ้าจิ้งจอกก็ได้เห็นบอสแห่งแก๊งมาเฟียสารเลวอยู่ตรงหน้า-เจ้าจิ้งจอกได้พูดออกมาว่า-"ทำไมแกต้องทำให้เพื่อนพ้องของเข้า-อาจารย์ของข้าเสียขีวิตด้วย-บอสแห่งแก๊งมาเฟียสารเลวก็ตอบกลับมาว่า-"แกน่ะ-ยังไงแกก็เป็นไอ้เจ้าจิ้งจอกที่โง่อยู่ดี-"แต่เป้าหมายของฉันน่ะ-ต้องการยึดชายแดนที่บอสแกคุมอยู่-รวมถึงจะปลดชีวิตแกด้วย"-บอสแห่งแก๊งมาเฟียสารเลวได้กล่าวออกมาด้วยความเกรี้ยวโกรธต่อจิ้งจอกที่ยืนอยู่ต่อหน้า-เจ้าจิ้งจอกได้บอกกลับมาว่า-"แต่ฉันนี้แหละ-ที่จะมาจบชีวิตแกเอง"
